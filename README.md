# Лабораторная работа 5 (Вариант 10)

## Условие задачи
Создать программу вычисления указанной величины. Результат проверить при заданных исходных значениях.
Формула: \(a = 2^{-x} \sqrt{x + 4\sqrt{|y|}} \sqrt[3]{e^{x - 1/\sin z}}\)
Параметр \(x\) – задается пользователем, \(y\) и \(z\) – константы.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Объявить переменные: `x` (вводимая), `y`, `z` (константы).
3. Задать константы: `y = -1.625e3`, `z = 0.512`.
4. Запросить у пользователя значение `x`.
5. Вычислить часть 1: корень 4-й степени из \(|y|\).
6. Вычислить часть 2: \(x + 4 \cdot \text{часть 1}\).
7. Вычислить часть 3: квадратный корень из части 2.
8. Вычислить часть 4: \(e^{x - 1/\sin(z)}\).
9. Вычислить часть 5: кубический корень из части 4.
10. Вычислить итоговый результат: \(a = 2^{-x} \cdot \text{часть 3} \cdot \text{часть 5}\).
11. Вывести результат на экран.
12. **Конец**
